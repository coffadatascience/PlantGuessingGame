# Plant Guessing Game (In Development)

## Overview

The Plant Guessing Game is a personal project aimed at creating an interactive educational platform for plant identification and care. It combines a rich botanical database with an extensive image library and problem-solving features to enhance learning for plant enthusiasts.

## Features

- Detailed plant database with scientific and common names, classifications, descriptions, and horticultural care information.
- Extensive image library linked to plants for visual recognition support.
- Problems data model to capture common plant issues, symptoms, causes, solutions, and severity.
- Flexible data structure allowing linking problems to plants, plant types, or families.
- Multi-language support, currently focusing on English and Dutch.

## Data Structure

### Plant Data Model
Includes comprehensive botanical attributes such as:

- Local and common names, family, genus, species
- Classification data and plant type information
- Descriptions, flowering status, colors, shapes
- Care requirements: light, water, soil, fertilization, pruning, temperature tolerance
- Image paths linked to a dedicated image repository

### Problems Data Model
Captures plant-related problems with properties:

- Problem ID, name, description
- Symptoms, causes, solutions, severity, and problem category
- Image path to visualize problems
- Designed to link with specific plants or more general plant groups

## Current Development

- Database seeded with core plant and problem data structure.
- Integration of a large image library ongoing.
- Developing problem recognition and solution modules.
- User interface and game mechanics under active construction.

## Motivation

This project reflects a passion for plants, ecology, and sustainable gardening. Beyond a fun guessing game, it aims to educate users on plant care and problem identification, offering value to hobbyists and professionals alike.
